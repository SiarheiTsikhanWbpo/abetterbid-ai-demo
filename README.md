# A Better Bid AI Care — demo concept

Русская интерактивная концепция поддержки покупателя автоаукциона.

**[Открыть демо](https://siarheitsikhanwbpo.github.io/abetterbid-ai-demo/)** · **[Возможности и данные для демо](capabilities.md)**

Неофициальный демонстрационный проект, не сервис A Better Bid. Профили, лоты и метрики вымышлены. Реальные звонки, CRM, ставки и платежи не подключены. Реплики подготовлены заранее.

Три сценария: допуск к торгам, доставка, документы после покупки. Для просмотра микрофон и регистрация не нужны. Поле названия компании сохраняется только локально в браузере.

Правила связаны с публичным [центром помощи A Better Bid](https://help.abetter.bid/hc/user-guide/en). Логотип взят с публичного сайта A Better Bid для демонстрационной концепции. Автомобиль — оригинальная SVG-иллюстрация. Шрифт Manrope: SIL Open Font License, см. [лицензию](assets/OFL-Manrope.txt).

## Локальный просмотр

Из каталога репозитория: `python -m http.server 8000`, затем открыть `http://localhost:8000/`.

Публикация GitHub Pages выполняется из корня основной ветки. Серверная часть исходного проекта в этом репозитории отсутствует.
