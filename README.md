# A Better Bid — клиентский AI-ассистент

**Помощь — рядом. Детали — под рукой.**

AI-ассистент для удобства покупателя: отвечает на вопросы в звонке, помогает получить ссылку или памятку в SMS или WhatsApp и дополняет живую поддержку.

**[Открыть демо](https://siarheitsikhanwbpo.github.io/abetterbid-ai-demo/)** · **[Возможности и данные для пилота](capabilities.md)**

Основной путь: вопрос в звонке → понятный ответ → детали в выбранном канале. Сотрудник поддержки остаётся рядом.

Неофициальный демонстрационный проект, не сервис A Better Bid. Профили, лоты и показатели вымышлены. Разговоры подготовлены заранее; сообщения показываются в предпросмотре, реальная отправка отключена. Телефон, микрофон и регистрация для показа не нужны.

Три примера: допуск к торгам, доставка, документы после покупки. В каждом есть отдельные образцы SMS и WhatsApp со ссылкой на официальный источник. Кнопка «Информация в SMS / WhatsApp» открывает предпросмотр; «Связаться с поддержкой» показывает подготовленный контекст для сотрудника.

Правила связаны с публичным [центром помощи A Better Bid](https://help.abetter.bid/hc/user-guide/en). Белый логотип взят с публичного сайта A Better Bid для демонстрационной концепции. Автомобиль — оригинальная SVG-иллюстрация. Шрифт Manrope распространяется по SIL Open Font License, см. [лицензию](assets/OFL-Manrope.txt).

Из каталога репозитория можно запустить `python -m http.server 8000` и открыть http://localhost:8000/.

GitHub Pages публикует только статическое демо. Серверная часть исходного проекта в этом репозитории отсутствует.
